## Regra de atualização

Uma mudança não está concluída quando altera comportamento, configuração,
rotas, permissões, infraestrutura ou procedimentos sem atualizar o documento
canônico correspondente. Não registre senhas, chaves, tokens ou bancos reais
em documentação ou no Git.
